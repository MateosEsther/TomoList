# TomoList
TomoList es una app web para gestionar lecturas de mangas y literatura.

## Objetivo
Crear una app web usable desde cualquier terminal, con front moderno,
autenticación real mediante Supabase, recuperación de password y almacenamiento 
persistente. 
La idea nace del proyecto final de ciclo creado con stack básico
para FP de desarrollo de aplicaciones web pero ahora con stack más moderno.

## Stack anterior vs. Stack previsto
- Frontend: JavaScript + HTML + CSS → React + Vite + TypeScript + SCSS
- Backend: PHP → Supabase
- BD: MariaDB/MySQL → PostgreSQL en Supabase
- Autenticación: sistema propio básico → Supabase Auth
- Control de versiones: N/A → Git + Github
