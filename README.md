# TomoList
TomoList es una app web para gestionar lecturas de mangas y literatura.

## Objetivo
Crear una app web usable desde cualquier terminal, con front moderno,
back separado, autenticación real, recuperación de password y almacenamiento 
persistente. La idea es original del proyecto final creado con stack básico
para FP de desarrollo de aplicaciones web pero ahora con stack de vanguardia.

## Stack anterior Vs Stack previsto
-Frontend: JS y HTML Vs React + Vite
-Backend: PHP Vs Java + Spring Boot
-BD: MariaDB Vs PostgreSQL
-Control de versiones: Git + Github
